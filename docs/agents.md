# Text cleanup with AI agents

- [Existing UnmarkAI Skill](https://github.com/DayBreak-u/unmarkai-skills/tree/main/skills/unmarkai-remove-text)
- [MCP setup and tool descriptions](https://unmarkai.net/video-text-removal-api/#api-agents-title)
- Hosted endpoint: `https://api.unmarkai.net/mcp`

Use the same API key as REST. Keep real credentials in your agent's local configuration or environment, never in a public issue. The Skill repository is the maintained setup guide; it covers local upload versus direct HTTPS import, source-pixel rectangles and result review.

For video translation, use the separate [REST examples](https://github.com/DayBreak-u/unmarkai-video-translation-api). Do not assume the cleanup MCP endpoint exposes a translation tool.
